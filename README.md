# Caro Vô Hạn

Tic-tac-toe / Caro bàn cờ không giới hạn. Không cần tài khoản.

- 🌐 Online: tạo phòng → gửi link `?room=xxxx` cho bạn
- 🤖 Chơi với máy
- 👥 2 người cùng máy
- Chọn 3/4/5/6 quân liên tiếp để thắng

## Chạy local
```
npm install
npm start
```
Mở http://localhost:3000

## Deploy Render
New → Web Service → chọn repo
- Build Command: `npm install`
- Start Command: `npm start`
